# Nordly Kork UF

Hemsida för Nordly Kork UF – ett Ung Företagsamhet-projekt som gör grytunderlägg, coasters och charkbrickor av återvunna vinkorkar.

Öppna `index.html` i en webbläsare för att se sidan, eller aktivera GitHub Pages (Settings → Pages → Deploy from branch → main) för att publicera den live.
